## 程式用途與執行方式

本程式整理聚餐名稱與餐費文字、進行型別轉換，計算 10% 服務費、折價券折抵後的應付總額與每人分攤金額，並判斷是否超過每人預算。

將儲存庫中的筆記本檔案下載或開啟於 Google Colab，依序執行三組測試儲存格即可重現輸出結果。

## 問題回答

### 1. 為什麼 `"4"` 要先轉成數字？
`"4"` 是字串（`str`），無法直接拿來做除法運算，字串相加也會变成文字串接而非數值相加；必須先用 `int()` 轉成整數，才能參與每人分攤費用的計算。

### 2. 如果先扣折價券，再計算服務費，第一組總額為何會變成 1,210 元？
先扣 100 元折價券後，計算服務費的基準會從 1,200 元變成 1,100 元；1,100 元的 10% 服務費是 110 元，因此總額會變成 `1,100 + 110 = 1,210` 元（比以原價算服務費的 1,220 元少 10 元）。
